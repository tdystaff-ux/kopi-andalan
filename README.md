# Kopi Andalan — Landing Page UMKM

Landing page modern premium untuk kedai kopi **Kopi Andalan**, dengan palet cokelat kopi dan krem.

## Fitur
- Tampilan responsif untuk desktop, tablet, dan smartphone.
- Hero section, profil usaha, katalog menu, galeri, testimoni, dan kontak.
- Navigasi mobile Bootstrap 5.
- Tombol pemesanan WhatsApp.
- Tahun copyright otomatis dengan JavaScript.
- Tanpa database dan tanpa backend.

## Teknologi
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3 (CDN)
- Google Fonts: DM Sans dan Playfair Display

## Cara Menjalankan
1. Ekstrak file ZIP.
2. Buka folder `kopi-andalan` menggunakan Visual Studio Code.
3. Jalankan `index.html` dengan ekstensi Live Server, atau buka langsung di browser.
4. Koneksi internet diperlukan untuk memuat Bootstrap dan Google Fonts dari CDN.
